# Preview original DWG locally in Web Studio

**Status:** proposed

Web Studio downloads the authenticated DWG Source by its exact child URI and renders it transiently in the browser with `@mlightcad/cad-simple-viewer`, reusing the existing Three.js 0.183 line through a scoped dependency override. The preview opens read-only, hides the viewer command line, keeps rendering out of the backend and Bundle, caps browser preview input at 25 MiB after a 92.6 MiB corpus sample blocked the main thread, keeps loading until progressive entity rendering finishes, enforces a 120-second total timeout, and shows explicit failure or incompleteness states instead of treating parser completion as canvas readiness. Upload remains capped at 100 MiB so larger sources can still enter the backend Bundle pipeline. Main-thread drawing is retained because a strict seven-file A/B changed all four worker-drawing page crashes into ready previews, although two difficult drawings still timed out and one ready case peaked near 2.5 GiB. The internal prototype pins MLightCAD's remote CAD font data; local Noto CJK and Droid fallback trials were rejected after corpus samples timed out or exhausted browser memory. Development mode enables the internal prototype; production builds include its worker assets only when `VITE_ENABLE_DWG_PREVIEW=true` is set explicitly. Acceptance requires the frozen corpus gates, a licensed production font source, and resolution of the LibreDWG worker's conflicting package-license metadata and corresponding-source obligations before customer distribution.
